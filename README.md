# Maze Runner

Maze Runner is a browser-based maze navigation game built using HTML, CSS, and JavaScript. The project focuses on responsive design, smooth player controls, and efficient game logic implementation.

## Features

- Real-time keyboard movement
- Responsive user interface
- Collision and goal detection
- Clean and lightweight design
- Replay functionality

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
